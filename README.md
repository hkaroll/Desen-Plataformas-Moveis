# Ecoponto ♻️

**Ecoponto** é um aplicativo desenvolvido para auxiliar os moradores de Fortaleza a encontrarem os pontos de coleta seletiva mais próximos de sua localização atual. 

Este projeto foi construído como requisito para a **Atividade Parcial da disciplina de Desenvolvimento de Plataformas Web** do Curso EAD de Análise e Desenvolvimento de Sistemas da Unifor.

## 🎯 Objetivo
O aplicativo visa aplicar na prática os conhecimentos de desenvolvimento para solucionar um problema real e de grande relevância social: facilitar e incentivar o descarte adequado de resíduos sólidos e materiais recicláveis.

## ✨ Funcionalidades Principais
* **Busca de Ecopontos:** Listagem e visualização dos locais de coleta seletiva na cidade.
* **Geolocalização (Sensor Nativo):** Integração com o sensor de **GPS** do dispositivo para capturar a posição do usuário e indicar as rotas/pontos mais próximos.
* **Interface Intuitiva:** Telas projetadas com base nas diretrizes do **Material Design** e boas práticas de UX/UI, garantindo uma navegação fluida.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem e Framework:** Android Nativo (Kotlin e Jetpack Compose).
* **Design e Prototipação:** Wireframes criados via Figma.
* **Versionamento:** Git e GitHub.
